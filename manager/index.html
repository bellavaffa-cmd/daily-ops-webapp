Per-warehouse operations settings for Daily Ops

🕐 Operating hours

Local open/close for the selected warehouse. Drives Open/Closed status and the CS completion ETA.

⏱️ Cut-offs

Local cut-off times. Drive the today/tomorrow split and at-risk flags.

Orders with the chosen tag(s) that flowed in within a time window are due by a cut-off. Same day = today, next day = tomorrow (resolved live; a batch stays visible until its deadline, and the deadline skips non-operating days). Shown on the dashboard's Cut-off countdown with the open count, countdown, and on-track/at-risk.

⏳ Aging thresholds

Per-carrier threshold (in days) for unfulfilled B2C orders in any status (Open, Picking, Packing, …). An order shows as aging on the B2C tab once its age reaches its carrier's threshold. Carrier is the Channel parsed from the WMS note (e.g. tiktok, shopee). The * row is the default for any carrier without its own row. Global — applies to all warehouses.

🍽️ Lunch / breaks

Break windows feed the CS “Est. completion” ETA — completion times skip lunch, breaks and closed hours (in the warehouse’s timezone). Add a row for each break.

🗂️ Tabs each role can see

For the selected scope and role, choose which tabs are visible. The Default (all warehouses) config applies everywhere unless a specific warehouse overrides it; a per-user override (in the roster above) beats both.

📺 Instance profiles

Named warehouse + tab scopes for shared screens / phones without a WMS account. A device signs in with the profile's login username + password (the app shows a login gate); it can't be changed from Settings — only by logging out and back in, or when a WMS ID ties to the device (which takes over). Empty warehouse or tab list = no limit on that dimension.
