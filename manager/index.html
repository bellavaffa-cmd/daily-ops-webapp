⏱️ Cut-offs & operating hours

Local times for the selected warehouse. Drives the today/tomorrow split, at-risk flags and Open/Closed status.

🚚 Carriers

Carriers available for this warehouse (used by the error-report form).

🔗 Webhooks

HTTP endpoints (e.g. Slack incoming webhooks) notified for this warehouse.

👥 User roles

Assign each user a role. Scope is per warehouse (or "All warehouses"). Admin/Manager can open this console.

🗂️ Tabs each role can see

For the selected warehouse and role, choose which tabs are visible. "All warehouses" applies as the default when a warehouse has no override.

📺 Instance profiles

Named warehouse + tab scopes for shared screens / phones without a WMS account. A device signs in with the profile's login username + password (the app shows a login gate); it can't be changed from Settings — only by logging out and back in, or when a WMS ID ties to the device (which takes over). Empty warehouse or tab list = no limit on that dimension.

ProfileWarehousesRole

Visible tabs are determined by the profile's Role (configured in “Tabs each role can see”). No role = all tabs.
